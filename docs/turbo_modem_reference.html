Turbo RX — Complete Block Reference & Canon / Optimality / Wiring Audit Every block of the streaming turbo receive path (V3Session), what it is, how it is wired, and whether it is canonical, optimal and correctly connected · 2026-07-04 · branch feat/ssb-rx

Scope. This documents the complete turbo receive pipeline — the streaming, superframe-aware V3Session decoder (modem-core/src/v3_session.rs) driven by RxV3Worker / run_turbo_worker (modem-worker/src/rx_v3_worker.rs), its front-end DSP, equaliser, synchronisers, soft demapper and SISO-LDPC turbo loop — as opposed to the OTA-validated rx_v2 batch decoder (the source-of-truth "legacy" path, left untouched). It supersedes the earlier canon-demodulator note (which covered only block B07) by covering all 15 blocks, and adds a per-block canon / optimality / wiring audit. The turbo path is opt-in at the worker level (turbo = true) and off by default in the GUI.
Headline verdict. The turbo pipeline is fundamentally canonical and correctly wired. Across 15 blocks and 4 end-to-end wiring traces there is no high-severity confirmed defect and no mis-wiring: every block is canonical or minor-deviation, and every connection is correct or questionable (never miswired). The soft turbo loop (extrinsic feedback, no double-counting), the FSE equaliser (FFE-frame NLMS, ridge-loaded LS), the DVB-S2X constellations (validated against the EN 302 307 tables), the synchronisers (Schmidl&Cox, normalized MF/GLRT) and the RaptorQ assembly (RFC 6330) are all textbook. The findings are one medium correctness item (RaptorQ symbol-size alignment, §3.2 F1) and a cluster of low-severity items: a known shared-tap loop-fighting pattern the joint-estimator pivot already targets, Pi-4 compute waste in the hot loop, and stale doc/label drift. Details in §3.

1. End-to-end signal flow & crate map

The turbo RX consumes 48 kHz real audio in ≤100 ms sub-pushes and tracks the transmitter's superframe cadence continuously. The transmit frame is V3/V4 (headerless): a passband preamble, a bootstrap marker carrying profile_index, an LMS warmup, a meta codeword, then data segments (marker → 2 codewords + pilots). The whole PRE+marker+warmup+meta block is re-inserted every 4 s as a fresh anchor — one superframe (SF). Signal path, as actually wired:

Crate map (which copy is live)

The workspace carries two parallel DSP layers. The live turbo path spans both, so knowing which copy runs matters (§3.4):

  • modem-core-base supplies the low-level streaming primitives the session imports (v3_session.rs:59-62): StreamingDsp (B01), StreamingFfe (B02/B07), RxEstimator (B08), plus rrc and sync::fse_decim_factor.
  • modem-core supplies everything the session touches by crate::: the FSM/canon-demod glue (B07/B11/B12), soft_demod (B09), ldpc::decoder (B10), cfo (B04), turbo_gate/fd_acquire (B03), marker/frame (B11), profile/pilot/constellation (B15).
  • modem-worker owns orchestration (B13); modem-framing owns RaptorQ (B14).
  • The modem-core-base copies of soft_demod, ldpc, demodulator, equalizer and pll are dead for the turbo path (nothing outside base imports them — verified by workspace grep). See §3.4 F8.

2. Block reference (B01–B15)

B01 Front-end DSP — StreamingDsp canon: minor-deviationopt: acceptablewiring: correct

Role Turn 48 kHz real audio into a fractionally-spaced (T/2) matched-filter symbol stream.
Algorithm (1) complex heterodyne NCO downmix at each absolute audio index (phase reconstructed from the absolute index m, not an accumulator → phase-continuous across chunks & rewinds; cfo_hz=0 is a bit-exact no-op). (2+3) ONE fused polyphase-RRC dot product per output that simultaneously does fractional resample (drift/SFO), RRC matched filter, and T/2 decimation — a 1024-phase precomputed bank, each row renormalised to constant DC gain so interpolation is DC-flat. Row-0 (frac=0) is bit-for-bit the legacy energy-normalised RRC. Canonical: RRC matched filter (Proakis) + polyphase interpolating FIR / Farrow-equivalent fractionally-spaced sampling (Harris; Erup/Gardner/Meyr).
Wiring ← V3Session.audio_buffer (worker push) → StreamingFfe.push_raw (B02). set_cfo_hz (from B04) folds into the downmix NCO; set_resample_step (from B05) drives the resampler.
Key symbols streaming_dsp.rs:342 feed_audio · :392 run_downmix_raw · :423 run_poly_rrc_decimate · :54 build_rrc_polyphase_bank · :289 rewind_to (byte-exact) · :328 warmup_samples
Notes The module header says "overlap-save" but the implementation is a single rolling delay-line time-domain convolution (no FFT block-convolution) — a doc label, not a defect. The fused design already resolves the "front-end decimation review" over-compute concern: the bank is evaluated only at the ~2·Rs output phases, never at full 48 kHz.

B02 Fractionally-spaced FFE — StreamingFfe (+ forward DD-LMS) canon: minor-deviationopt: acceptablewiring: correct

Role A single live T/2 feed-forward equaliser, LS-bootstrapped then continuously adapted.
Algorithm Fractionally-spaced (T/2) FFE (Qureshi 1985; Proakis ch.10–11) with three adaptation modes on one tap set: (a) ridge-loaded LS install on the known preamble (train_ls_ridge, the canonical minimum-norm fix for the FSE Gram rank-deficiency on oversampled/clean signals), after an ML matched-filter-peak delay calibration; (b) continuous forward DD-LMS in push_raw (μ=0.008, hard nearest-point target with the LMS step scaled by soft reliability w=|E[a|y]|²/E[|a|²|y] so it cannot chase noise at low SNR — the fix for the documented turbo<legacy fading failure); (c) the code-aided soft joint FBF used by B07.
Wiring ← B01 fse samples → equalised sym_buffer/out_buf read by the marker probe (B11) and B07's canon demod. Training driven by the FSM (acquisition bootstrap; META anchor).
Key symbols streaming_ffe.rs:353-372 forward DD-LMS · :396 calibrate_delay · :561 train_lms_at (rebuild vs refine) · :758 reequalise_span_joint · :1068-1077 FFE-frame NLMS · v3_session.rs:302 forward_decision · :334 make_forward_slice
Strength The NLMS target is derived in the FFE (pre-derotation) frame e_ffe=e_rot/A, which avoids the 1/|g|² step blow-up that a naïve e·conj(A) would cause on a fade.
Finding low the single live tap vector is mutated by several loops (forward DD-LMS + per-segment FBF + backward/retry) — see §3.2 F2 (loop-fighting; joint-estimator pivot target).

B03 Acquisition & gating — TurboGate / ScDetector / preamble MF canon: canonicalopt: acceptablewiring: questionable

Role Cold-start detection: find a burst, classify its geometry family, trigger the FSM.
Algorithm Three textbook detectors. (1) Normalized FFT matched-filter metric |Σw·t|²/(E_t·E_w) (fd_acquire.rs:253) — the canonical GLRT / normalized-correlation detector for a known signal of unknown amplitude in white noise (Proakis), zero-padded for linear correlation. (2) Schmidl&Cox marker-pair auto-correlation metric (ScDetector) firing the FSM. (3) near-orthogonal 256-QPSK per-family preambles (cross/auto ≈ 16/256) → a single-pass ML geometry classifier. False positives are handled by a deferred-decision architecture: soft floors (MF 0.15 / SC 0.5) only trigger a seek; the hard gate is marker Golay(24,12)+CRC + a RECEIVING grace window.
Wiring ← raw 48 kHz audio → FSM lock (B11), CFO estimate (B04), profile choice (B13/B15). rx_v2::detect_best_profile_cold is dead on the turbo path (worker bootstraps via the gate).
Key symbols fd_acquire.rs:253 MF metric · turbo_gate.rs:224 gate · v3_session.rs:3799 ScDetector · :3827 push · :1731 try_acquire_preamble
Finding low ScDetector recomputes the S&C metric O(W) per sample (W=1024) instead of the canonical O(1) recursive update, and keeps running even when Locked — Pi-4 compute waste (§3.2 F3).

B04 Carrier-frequency (CFO / NCO) recovery canon: minor-deviationopt: acceptablewiring: correct

Role Acquisition-only, one-shot-per-burst carrier-offset estimate for SSB/QO-100 (±250 Hz).
Algorithm Two open-loop stages. Stage 1 (cfo.rs:193): Welch-periodogram cross-correlated against a raised-cosine |H|² band-shape template — a band-shape matched template (correct for a suppressed-carrier RRC signal with no discrete line), giving a biased but bracketing coarse estimate. Stage 2: a ±15 Hz grid scored by the unbiased time-domain matched-filter metric with parabolic sub-bin refinement — the value actually committed. Canonical: DA/NDA frequency estimation (Mengali&D'Andrea; Luise&Reggiannini) + periodogram-max/parabolic interpolation. A snap_deadband collapses |cfo|<1.5 Hz to exactly 0.0 (bit-exact no-op).
Wiring ← raw passband window (PSD reused from the gate) → set_cfo_hz → B01 NCO → reboot_pipeline_and_replay. Latched once per burst (cfo_locked).
Key symbols cfo.rs:193 coarse · :52 snap_deadband · v3_session.rs:1134 set_cfo_hz · :1811 cfo_locked
Finding low the module docstring advertises the DEAD Kay single-lag estimator (estimate_fine_cfo) as the live fine stage — pure doc drift (§3.2 F7).

B05 Symbol-timing / SFO loop — PreambleSfoTracker canon: canonicalopt: acceptablewiring: correct

Role Track slow sample-clock offset (SFO / drift) and steer the front-end resampler.
Algorithm Data-aided symbol timing on the known constant-modulus entry preamble: parabolic sub-sample interpolation of the matched-filter magnitude gives the timing phase τ; the two-preamble (≈4 s apart) φ-slope is the residual SFO, integrated (gain 0.5) into the smooth-resampler rate. It is effectively closed-loop (residual measured on the post-resampler T/2 stream) and applied through a continuous phase accumulator (smooth velocity change, no phase discontinuity). Canonical: modulation-independent DA timing (Meyr ch.5) — deliberately avoids the per-ring AbsGardner self-noise/bias for the APSK/AWGN target. Default-ON (kill-switch V3_NO_TIMING_LOOP); byte-exact when the rate settles to unity on a drift-free capture.
Wiring ← B01 post-resampler fse + preamble positions (B11) → B01 set_resample_step. Cleanly owns only the slow rate; carrier/CFO own phase; the discrete coarse-drift B06 is fully bypassed (timing.is_some() early-return) → no loop-fighting.
Key symbols v3_session.rs:95-224 PreambleSfoTracker · :182-208 residual→rate · :1008 kill-switch · rx_v2.rs:1202 estimate_drift_gardner (dead when B05 on)
Notes low the ready-made one-shot two-preamble SFO seed is left unwired (cold-starts at unity each burst); two-point slope has no cross-anchor regression — both low-impact for AWGN.

B06 Coarse linear-drift estimation & commit (2-preamble / Gardner) canon: minor-deviationopt: suboptimalwiring: questionable

Role Legacy discrete drift-ppm estimate + rewind/replay — the fallback for B05.
Algorithm estimate_drift_gardner is an OLS line-fit of measured marker positions vs nominal (the canonical feedforward "position-slope" SFO estimator, Meyr), with quality gates (residual RMS<2 samples, |ppm|<200). The two-preamble path measures the slope between the entry and boundary preambles. A committed ppm triggers replay_from_anchor over the full history. Discrete commit-rebuild rather than continuous integration — the less optimal actuation, which is why B05 supersedes it.
Wiring Both paths early-return on timing.is_some() (v3_session.rs:3423, 3537), so they never fight B05. Default-OFF (V3_2PRE_DRIFT); strictly one-shot (drift_locked). The double-count guard uses the absolute estimate, not from_ppm+estimate.

B07 Canon demodulator — canon_demod_segment (the turbo core) canon: minor-deviationopt: acceptablewiring: questionable

Role Per-segment SISO turbo demodulation: joint equalise + phase-track + soft-demap + LDPC + re-seed.
Algorithm A code-aided iterative estimator in the turbo-equalization family (Tüchler/Koetter/Singer 2002). Each of up to 5 passes: build soft references (pilots w=1; data E[a] with MMSE weight w=|E[a]|²/E[|a|²], 0 at iteration 0) → one joint FFE+phase forward-backward-forward (FBF) NLMS pass in place folding a per-group pilot LS gain and an intra-group bidirectional DD-PLL phase, with the persistent carrier model predicted first → per-symbol σ²(t) → per-CW llr_maxlog_per_sym → LDPC decode_soft → soft symbols from the extrinsic → next pass; break when every codeword's syndrome clears. Strictly soft (no hard-decision path), so a corrupted segment yields E[a]≈0 → w≈0 and cannot poison the live taps. Canonical: turbo equalization + per-symbol BICM reliability weighting + code-aided (Colavolpe/Barbieri/Caire 2005) gain/σ² estimation.
Wiring ← B02 taps + B08 carrier + B15 pilots → B09 LLR → B10 LDPC → B14 CwDecoded. Carrier model updated forward-primary only (out-of-order re-decodes predict read-only).
Key symbols v3_session.rs:2082 canon_demod_segment · :2147 SISO loop · streaming_ffe.rs:758 reequalise_span_joint · :990-1027 bidirectional DD-PLL
Findings low the "RTS / two-filter smoother" label is an equal-weight 0.5/0.5 bidirectional DD-PLL average, not an inverse-covariance Fraser-Potter/RTS smoother (§3.2 F5); low the FBF adapts the persistent taps even on backward/retry and non-converged segments with no rollback (§3.2 F2). Both benign on AWGN; matter for phase-noise/fading channels.

B08 Persistent carrier phase/frequency — RxEstimator canon: minor-deviationopt: acceptablewiring: correct

Role A slow, session-persistent carrier {θ,ν} model that predicts each segment's phase ramp.
Algorithm A decision-directed 2nd-order phase/frequency tracker recast as a per-segment predict/correct recursion (Meyr/Moeneclaey/Fechtel ch.5/8; Mengali&D'Andrea): phase predicted as θ + ν·(s−anchor); after the forward-primary decode, θ is set to the measured residual phase at the segment's last symbol (G_phase=1) and ν integrates the residual slope with gain 0.5. Default-ON (kill-switch V3_NO_CARRIER_TRACK); identity model on the first segment → pred≡0 → byte-identical bootstrap.
Wiring ← B07 residual (forward-primary only) → B07 carrier_pred. Correctly protected from out-of-order corruption (update_carrier=false on backward/retry).
Key symbols rx_estimator.rs (predict/update) · v3_session.rs:2138 carrier_pred · :2291 update gate
Notes No confirmed issue. Composes with B07's intra-group DD-PLL and the pilot gain-phase — a fold candidate for the joint estimator (§3.3), not a defect.

B09 Soft demapping / LLR + posterior→soft-symbol canon: canonicalopt: acceptablewiring: correct

Role Convert equalised symbols → per-bit LLRs, and LDPC extrinsic → soft symbols E[a],Var[a].
Algorithm llr_maxlog/llr_maxlog_per_sym is the standard max-log-MAP BICM demapper (per-bit LLR = (min_{b=1}|y−s|² − min_{b=0}|y−s|²)/σ²), with per-symbol σ²(t) giving faded symbols near-erasure LLRs. soft_symbols_from_posterior_llr forms E[a]=Σ a·P(a) and Var[a] from the decoder extrinsic (numerically robust: stable-tanh logistic, var floor, normalisation guards). Canonical: max-log-MAP BICM demapping; posterior-mean soft symbols. Sign convention (positive=bit0) and MSB/LSB labelling are unit-test-guarded (the classic inverted-LLR trap).
Wiring Live copy is modem-core (v3_session.rs:57 use crate::soft_demod), not the richer base copy. ← B07 out[] / B10 extrinsic → B10 / B07.
Key symbols soft_demod.rs:15 llr_maxlog · :61 llr_maxlog_per_sym · :140 soft_symbols_from_posterior_llr

B10 LDPC SISO decode + turbo iteration canon: canonicalopt: acceptablewiring: correct

Role Soft-in/soft-out LDPC decode of each codeword, returning info bits + extrinsic for the equaliser.
Algorithm Layered Normalized Min-Sum over the WiMAX IEEE 802.16e QC-LDPC codes (N=2304): the two-smallest-magnitudes + sign-product check update with ALPHA=0.75 normalisation (Chen&Fossorier 2005; ~0.2 dB from SPA). The extrinsic is damp·(posterior−seed) with seed=clamp(channel+a-priori) — provably no double-counting (subtracts channel AND a-priori). A pulp-SIMD twin (decode_soft_simd) is bit-identical to the scalar path (test-verified across rates and at strong/marginal/noise inputs). Fail-stop bails on syndrome stagnation. Both SIMD and fail-stop are now default-ON kill-switches.
Wiring Live copy is modem-core's decoder (v3_session.rs:51); base decode_with_posterior is dead. In the SISO loop, a-priori into the LDPC is always None — feedback recirculates only through the equaliser (the equaliser-half of turbo-EQ), structurally avoiding the BICM-ID self-feedback hazard.
Key symbols ldpc/decoder.rs:226 decode_soft · :312-315 extrinsic · :446 decode_soft_simd · :60-62 fail-stop
Finding low stale comments at the live call sites misname the knobs (decoder.rs:292 "opt-in V3_LDPC_FAIL_STOP", v3_session.rs:2246 "V3_LDPC_SIMD; default scalar") — both are actually default-ON V3_NO_* kill-switches (§3.2 F9). Doc-only.

B11 Superframe FSM + markers + cycle advance canon: minor-deviationopt: acceptablewiring: correct

Role The Idle→Acquiring→Locked state machine: acquire, validate markers, predict the cadence, advance.
Algorithm Acquisition preamble = coherent FFT matched filter vs the 256-sym template (DA, canonical). B12 Backward flywheel / late-entry / replay-from-anchor canon: minor-deviationopt: acceptablewiring: correct

Role Ride through missed markers and recover data emitted before a late RX entry.
Algorithm Decision-directed coasting through outages (accept only self-validating converged CWs — noise never converges, so it cannot poison), plus deterministic state rewind + forward-replay-to-head: rewind the live DSP to a warmup margin before the target, replay the borrowed history forward to the live head, which reproduces the earlier fse the FFE never saw and returns every cursor byte-exact (proven by streaming_dsp continuity tests). Canonical: flywheel/coast + late-entry acquisition; the no-copy rewind/replay is the deterministic-replay pattern.
Wiring ← missed-marker / late-entry events (B11) → re-decoded segments (B07) → CwDecoded. Carrier estimator explicitly protected (update_carrier=false read-only prediction). Zero cost on a clean start (entry_esi==0 early-returns). Default-ON (V3_NO_BACKWARD).

Finding low the in-window backward flywheel mutates the live FFE taps as a side effect — asymmetric with the read-only-protected carrier estimator (§3.2 F2). Benign on AWGN.

3.2 Prioritized findings

Severity-verified: the per-block findings below survived an independent adversarial refutation pass; the wiring-trace items (§3.3) that overlap them are corroborated. Nothing is high-severity.

F1 · medium · correctness · B14. T=108 (LDPC info bytes) is not a multiple of 8, so ObjectTransmissionInformation::with_defaults(k·T, T) picks alignment=8 and symbol_size = 108 − (108%8) = 104. The transmitted k_symbols then understates the true source-symbol count and ~3.7% of channel payload is zero-pad. Invisible with the 30% over-provisioning (which is why it passed byte-exact OTA), but it dents efficiency exactly on the primary payload profile and at the ~10% ESI-loss threshold the project benchmarks against.
Fix: explicit OTI ObjectTransmissionInformation::new(padded_len, T, 1, 1, 1) at raptorq_codec.rs:46,97 so symbol_size==T for all profiles.
F2 · low · wiring/correctness · B02·B07·B12 (recurs in §3.3 L2/L3). The single live tap vector current_taps is mutated by ≥3 loops with no rollback: continuous forward DD-LMS in push_raw (μ=0.008, hard target), the per-segment turbo FBF NLMS (μ=0.02, soft target, ×3 legs ×≤5 iters), and backward/retry re-decodes — which run with update_carrier=false (protecting the carrier model) but still adapt the taps in place. The retry_failed_segments docstring even claims a "local tap copy" that does not exist (v3_session.rs:2621 vs streaming_ffe.rs:1072-1077). Benign on the characterised AWGN channel (DD-LMS re-converges to the same MMSE solution; measured net-positive), but it is real loop-fighting and the asymmetry with the read-only carrier protection is a latent poison path on fading/low-SNR.
Fix: snapshot+restore current_taps around update_carrier=false re-decodes (cheap, bounded), and fix the stale docstring. Structurally, this is exactly what the joint-estimator pivot consolidates.
F3 · low · optimality · B03. ScDetector recomputes the Schmidl&Cox R/P1/P2 as a full W-length sum on every pushed sample (W=1024 for family A) instead of the canonical O(1) recursive accumulator, and keeps running unconditionally through the whole Locked burst — ≈50 MMAC/s of avoidable work on the Pi-4 idle budget the gated architecture exists to protect.
Fix: recursive sliding accumulator (byte-neutral to the edge-trigger), and/or skip sc.push when Locked.
F4 · low · optimality · B09 (recurs L1/L3). soft_symbols_from_posterior_llr allocates and fills ring_prob/ring_cond_num and calls rings() per symbol, but the live path reads only mean/var (v3_session.rs:2274-2276). This is dead work in the hottest turbo inner loop (per-CW × per-iteration × up to 6 passes). The ring statistics belong to the still-shelved per-ring EM / soft-DFE lever.
Fix: a lean mean/var-only variant for the live path; keep the ring outputs feature-gated behind the shelved lever.
F5 · low · canon (labelling) · B07. The comment calls the phase smoother a "two-filter / RTS form", but the code is two reset 2nd-order DD-PLLs averaged 0.5/0.5 (streaming_ffe.rs:990-1027). A true Fraser-Potter two-filter smoother combines forward/backward by inverse-covariance weighting; an RTS smoother is forward-Kalman + backward covariance recursion. Equal weighting under-corrects the endpoints (each direction's unconverged transient gets half-weight). Fine on AWGN; suboptimal on QO-100 phase-noise.
Fix: relabel as "equal-weight bidirectional DD-PLL average"; if phase-noise proves limiting, weight by each direction's convergence age.
F6 · low · optimality · §3.3 L1. Inside reequalise_span_joint the tap-invariant equalised sample y[k]=Σ taps·frac_buf is recomputed with identical taps in the gain pass and both phase-smoother legs (streaming_ffe.rs:849, 1006, 1041). Hoisting it to one per-iteration Vec is byte-exact-preserving and saves two full convolutions per iteration (Pi-4).
F7 · low · doc · B04.   F9 · low · doc · B10. Doc/label drift that misleads an auditor: cfo.rs:16-18 advertises the dead Kay estimator (estimate_fine_cfo) as the live fine stage (the live path is PSD-template coarse → MF-grid parabolic refine); and the live LDPC call sites misname the knobs — decoder.rs:292 "opt-in V3_LDPC_FAIL_STOP" and v3_session.rs:2246 "V3_LDPC_SIMD; default scalar" are both actually default-ON V3_NO_LDPC_FAIL_STOP / V3_NO_LDPC_SIMD kill-switches. Rewrite the comments to name the live path.
F8 · low · wiring hazard · §3.4 L4. modem-core-base holds DEAD, DRIFTED duplicates of soft_demod and the LDPC decoder (plus demodulator, equalizer, pll) with the same public API as the live modem-core copies — nothing outside base imports them (verified by workspace grep). Two decoders with the same name, one dead and already drifted (the base soft_demod is richer), is a real maintenance/wiring hazard.
Fix: one source of truth — keep the module in base and re-export from core, or delete the dead base copies. sync is genuinely live in both crates for different helpers, so it needs a real plan, not deletion.
F10 · low · correctness (latent) · B15. net_bitrate computes gross = symbol_rate · bps · tau, but the on-air symbol rate under faster-than-Nyquist is R_s/tau (closer spacing → more symbols/s). Zero live impact (every shipping profile is tau=1; the only tau≠1 profile, MEGA, is removed from the registry), but dimensionally wrong. Fix: divide by tau.
F11 · low · canon (subtlety, raised by §3.3 L3, not independently refuted). The equaliser output fed to the demapper is not strictly extrinsic: because the joint FBF adapts the shared span taps/gain using each data symbol's own a-priori E[a], a symbol's a-priori partially leaks into its own channel LLR. Canonical MMSE turbo-EQ (Tüchler) forms symbol k's output excluding its own a-priori. The leak here is diffuse (an averaged adaptation effect, weight-bounded) and small on AWGN. The clean fix is again the joint code-aided estimator; until then it is a documented theoretical departure, not a decode bug.

A deliberate trade-off that is not a finding — the META LS rebuild

A wiring trace flagged that the default META-anchor path does a full LS rebuild every superframe (rebuild_meta = V3_FFE_REFINE.is_none(), default true), which superficially contradicts the project's "refine, don't rebuild" rule (a rebuild lets one bad frame corrupt the chain). On inspection this is a deliberate, measured choice, documented at v3_session.rs:2033-2039: on faded low-SNR NORMAL captures a fresh rebuild at every anchor recovers more unique ESI than refine-only or best-of-two (diag 160 vs 156) — "when every anchor is weak there are no good taps to protect, so the extra re-centring wins" — and it is the original OTA-validated behaviour. The refine / best-of-two path is available via V3_FFE_REFINE for A/B. So the refine-not-rebuild rule holds between anchors (continuous forward DD-LMS, §B02); the per-anchor rebuild is the intended, empirically-won exception. No action needed.

3.3 Cross-cutting themes

  • Shared-tap loop-fighting (F2, F11). One tap vector, several writers, no rollback; the carrier estimator is read-only-protected but the taps are not. Benign on AWGN, latent on fading. The joint-estimator pivot is the structural fix. Note the timing/drift estimators (B05/B06) are not among the fighters — they are cleanly gated by timing.is_some().
  • Pi-4 compute waste in the hot loop (F3, F4, F6, + GUI diagnostics recomputed every iteration, v3_session.rs:2200-2225). All byte-exact-preserving optimisations; worth doing before the next Pi-4 perf pass, none change decode behaviour.
  • Doc/label drift (F5, F7, F9, the "local tap copy" docstring). Cheap to fix, real auditor-confusion cost — several comments name dead code or wrong knob defaults.
  • Dual-crate dead duplicates (F8). The single biggest maintenance hazard: two same-named decoders/demappers, one dead and drifting.

3.4 Relation to the joint-estimator pivot

Within one reequalise_span_joint pass three phase corrections compose into A = cphase · inv_gain · exp(−jθ): the persistent carrier from B08, the per-group pilot LS gain-phase, and the intra-group DD-PLL (B07). This is a correct cascade (each stage estimates the residual the previous left), and it is stable and byte-exact where it should be — but it is exactly the stack the pivot (project_joint_estimator) proposes to replace with one code-aided state-space (Kalman/RTS) estimator. The audit corroborates the pivot's premise and sharpens its scope:

  • Fold candidates: B07 intra-group DD-PLL + B08 carrier {θ,ν} into one state vector; B05 timing-rate as a third state.
  • The tap writers (F2) should be the first thing consolidated under a single owner with rollback.
  • Do not list B05/B06 as loop-fighters — they are already cleanly separated; the fight is among the phase/gain/tap loops, not the timing loop.

5. Method & references

This document was produced by a multi-agent audit of the branch feat/ssb-rx source (2026-07-04): 15 blocks were each deep-read into a structured dossier, audited on three axes (canon / optimality / wiring) against the literature below, and each material finding put through an independent adversarial refutation pass (47 agents total). Four end-to-end wiring traces (signal-flow/compute, state-continuity, soft-turbo-loop integrity, defaults/dual-crate) cross-checked the block-level results. The three most consequential wiring-only claims (META rebuild default, dead base duplicates, duplicate FIR convolution) plus the SIMD/fail-stop defaults were re-verified directly against the code by the author. Every claim is anchored to file:line; where a claim could not be proven from code + reference it is marked so rather than asserted.
